## File guidelines

- Use **JPG** for photographs, **PNG** when transparency is needed (logos, icons).
- Aim for **1600 px** on the longest edge — sharp on Retina without bloating page weight.
- Compress to **~250–400 KB** per image. Free tools: <https://squoosh.app> or <https://tinypng.com>.
- Filenames are lowercase, hyphenated, no spaces.
